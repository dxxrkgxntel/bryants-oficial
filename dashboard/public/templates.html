Una base sólida
para cada servidor.

Exporta una copia de los ajustes de módulos para guardarla como plantilla o restaurarla en otro servidor que administres. La importación usa las validaciones del dashboard y no copia listas de registros.

Administrar plantillas

Necesitas iniciar sesión con Discord y tener permisos administrativos en el servidor de origen y el de destino.

1. Exportar configuración

Selecciona un servidor y descarga una copia JSON de los ajustes de sus módulos. Guárdala en un lugar privado; puede contener mensajes personalizados, IDs de canales y roles.

2. Importar a otro servidor

Elige un archivo exportado y un servidor de destino. Se actualizarán únicamente los módulos de configuración presentes en el archivo; los módulos de lista (por ejemplo, registros o elementos añadidos) no se borran ni se copian.
